# ⚡ Hizz Analiz - ilk galiba? 

Selam canım **skiderim** benim Kuru kodu yaz, tara, gör. 

### 🚀 Mevzu Ne? (Özellikler)

* **Görsel Şov(Tamam bunda Claude.ai dan yardım aldım) :** Sadece kuru tablo vermiyoruz, Chart.js ile grafiklerin dibine vuruyoruz. Sınıf ortalamaları, puan dağılımları... Hepsi cillop gibi önünde.
* **Okulları Kapıştır:** "Bizim okul mu daha iyi, Coo mu? " diye merak ediyorsan kurum kodlarını gir, kıyasla, kimin daha yüksek ortalaması var gör.
* **Okul Bulucu:** "Okulun kodunu unuttum kanka" dersen il/ilçe seçip okulunu şak diye buluyorsun.(hizlı deneme sitesinin apisi) 
* **Gece Kuşu Modu:** Gece 3'te deneme analizi yaparken gözlerin kanamasın diye Dark Mode ekledim, kıymetimi bil.
* **Rapor Al:** İstersen sonuçları CSV yap Excel'de takıl, istersen PDF çıkar hocaya göster. Paşa gönlün bilir.

### 🛠 Arka Sokaklar (Teknoloji)

* **Saf JavaScript:** Framework falan kasmadım, Vanilla JS sağolsun. `fetch` istekleri havada uçuşuyor.
* **CSS Modernliği:** Değişkenlerle, flexboxlarla, gridlerle tasarımı jilet gibi yaptık.
* **Kütüphaneler:** Font Awesome (ikonlar için), Chart.js (grafikler için) ve PDF mevzuları.
